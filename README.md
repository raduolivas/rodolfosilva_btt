# RodolfoLabs

Official source repository for https://www.rodolfolabs.it.

## Stack
- Next.js
- React
- TypeScript

## Current pages
- `/` — RodolfoLabs homepage foundation
- `/community` — community foundation
- `/career-check` — lead generation / Tech Career Check foundation
